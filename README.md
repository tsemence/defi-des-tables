# Défi des tables

Mini-application de calcul pour navigateur et tablette Android. Multiplications, divisions exactes, divisions avec reste, chronomètre et bilan.

## Publication sur GitHub Pages

1. Créer un dépôt GitHub public nommé `defi-des-tables`.
2. Ajouter tous les fichiers de ce dossier **à la racine** du dépôt, y compris `icons/`.
3. Aller dans **Settings → Pages**, choisir **Deploy from a branch**, puis `main` et `/(root)`, et enregistrer.
4. Ouvrir `https://VOTRE-PSEUDO.github.io/defi-des-tables/`.

## Installation Android

Ouvrir l'URL dans Chrome, puis menu `⋮` → **Installer l'application** (ou **Ajouter à l'écran d'accueil** selon le navigateur). Après la première ouverture, l'application est disponible hors connexion.

Les préférences sont mémorisées localement. Aucun compte ou transfert de résultats n'est utilisé.
